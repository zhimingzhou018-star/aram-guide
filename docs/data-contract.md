# 英雄模块数据契约 V2

每名英雄使用独立的 `data/heroes/<slug>.json`。首页索引不得重复携带装备、海克斯和玩法详情。

## 必填模块

- `hero`：英雄 ID、slug、Riot ID、中文名、称号、外号与头像。
- `ranking`：当前排名、梯度、胜率、选取率和样本量。
- `build`：当前唯一推荐流派。
- `summonerSpells`：两个召唤师技能。
- `skillOrder`：三个技能的主副加点顺序。
- `items`：至少 1 件出门装、3 件核心装、6 件完整推荐装备。
- `augments`：棱彩、金色、银色各 6 个；单海克斯选取率均须大于等于 1%，推荐组合 4 组且不受该门槛限制。
- `gameplay`：3 条人工审核摘要，必须 `locked: true`。
- `sources`：版本、数据日期、来源限定。

## 发布门禁

- 任一模块缺失都会阻止整个候选批次替换当前数据。
- 装备、海克斯、召唤师技能不得使用纯数字 ID 充当显示名。
- ARAMKit 固定标记为第三方聚合数据：`region: unknown`、`dataLevel: aggregate`。
- 自动更新只能替换统计模块，不得覆盖已锁定玩法摘要。
- `legacy.poster` 可在模块数据加载失败时回退到旧攻略图。
